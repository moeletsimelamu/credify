**2. Neutralising proxy features** (gross_monthly_income, net_monthly_income, employment_type): test ROC-AUC 0.6934. Disparate impact by sex 0.978, by age band 0.842. Removing a feature that carries real risk signal costs accuracy and can move disparity elsewhere; the served model keeps all features, and these figures are recorded for reviewers.

**3. Not adopted.** Group-specific thresholds would need the protected attribute at decision time. Credify never uses it, so that option is out of scope by design.
